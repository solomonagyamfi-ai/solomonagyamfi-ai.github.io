# Employee Workforce Analytics

## Data Analytics Upskill Capstone Project

An end-to-end workforce analytics project developed as part of the Data Analytics Upskill Programme by Generation Ghana.

The project analyses employee demographics, education, employment status, salary and performance data to identify workforce patterns and generate actionable Management insights.

---

## Project Overview

### Business Objective

The objective of this project was to analyse a large employee dataset and transform raw workforce information into meaningful insights that could support management decision-making.

The analysis focused on:

- Workforce demographics
- Employee status
- Education levels
- Salary distribution
- Employee performance
- Departmental workforce patterns
- Departmental performance

---

## Dataset

The dataset contains information on:

- 30,000 employees
- 8 departments
- Gender
- Education
- Employment status
- Revenue
- Health Insurance
- Performance score
- Department information
- And more

## Analytical Process

### 1. Data Preparation

The dataset was first reviewed and cleaned using Microsoft Excel.

Activities included:

- Checking data quality
- Identifying missing values
- Reviewing data types
- Checking categorical fields
- Exploring distributions
- Preparing the dataset for analysis

### 2. SQL Analysis

MySQL was used to answer business questions and explore relationships within the dataset.

The analysis included:

- Aggregations
- Filtering
- Grouping
- Sorting
- Department analysis
- Employee status analysis
- Salary analysis
- Performance analysis

### 3. Power BI Dashboard

Power BI was used to transform the analysed data into an interactive dashboard.

The dashboard presents key workforce indicators and allows users to explore employee demographics, education, status, health insurance, revenue, and performance.

## Key Findings

### Workforce Status

| Employee Status | Percentage |
|---|---:|
| Active | 33.61% |
| On Leave | 33.52% |
| Inactive | 32.87% |

The workforce is relatively evenly distributed across the three employee-status categories.

### Education

| Education Level | Percentage |
|---|---:|
| Master's | 35.24% |
| Bachelor's | 33.32% |
| Diploma | 16.87% |
| Doctoral | 14.57% |

Master's degree holders represent the largest education group in the dataset.

### Salary

- Minimum salary: GHS 2,500
- Maximum salary: GHS 15,000

### Performance

The average employee performance score was approximately **3.60**.

### Gender

The dataset shows an approximately **50/50 gender distribution**, indicating a relatively balanced workforce representation.

## Business Insights

- Workforce composition
- Employee availability and status
- Educational qualifications

- Performance patterns

## Recommendations

Based on the analysis, organisations could:

1. Monitor employee status trends to improve workforce planning.
2. Analyse performance alongside education and departmental factors.
3. Review salary distribution to support compensation planning.
4. Use workforce dashboards for regular HR reporting.
5. Combine demographic and performance data to support evidence-based talent decisions.
